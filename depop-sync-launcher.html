Depop Sync Launcher

Safe test launcher for ABC is for XYZ. This does not change the Inventory app or the existing Depop scraper.
1. Install the scraper bookmark once
Drag this button to your browser bookmarks bar:
ABC Depop Sync
If dragging is blocked, right-click/copy the link address and create a bookmark manually with that JavaScript as the URL.
2. Open your Depop shopOpen ABC Depop Shop
3. Run the scraper on Depop
While the Depop shop tab is active, click ABC Depop Sync in your bookmarks bar. The existing scraper will scroll the listings, collect For Sale/Sold details, download its JSON, and ask whether to sync to Supabase.
4. Return to Depop StatusOpen Depop Status
Why the bookmark is needed: browsers do not allow the Inventory site to inject JavaScript into a separate Depop tab. Running the bookmark while Depop is active gives your existing scraper access to the listing page exactly as it has today.
